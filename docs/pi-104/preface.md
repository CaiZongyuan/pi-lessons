## 如何阅读本书



本书是某个 monorepo 在某次提交时的地图。其中的每条记录、每个事件和每项行数，都来自该检出版本的代码，或通过运行它而获得。



本书介绍 Pi，即以 `@earendil-works/pi-coding-agent` 1\.0\.4 发布的智能体运行框架。依据的是 `earendil-works/pi` 仓库的提交 `28dcce2`（2026 年 10 月 5 日）。全书沿着一个提示展开：从终端编辑器出发，经过提供商层和智能体循环，深入到 Pi 追加进会话文件的各行，然后再延伸到配置、扩展、运行模式和实验性包。

### 适合谁读



你是一名 TypeScript 工程师，用过编码智能体，希望嵌入、扩展、运维 Pi，或为它贡献代码。你知道什么是工具调用，但还没读过 Pi 的源代码。读完本书，你将能够预测 Pi 对给定会话会向模型发送什么，并逐行读懂会话文件。你还可以编写在正确事件上进行拦截的扩展，为集成选择运行模式，以及找到负责某项行为的文件。



### 本书如何编写



本书没有任何内容是凭记忆写成的。每节结尾都有一行“来源”，列明编写该节所依据的文件。来源的权威性按以下顺序排列：

|<strong>来源</strong>|<strong>路径</strong>|<strong>用途</strong>|
|---|---|---|
|源代码|提交 `28dcce2` 中的 `packages/*/src/**`|每个类型、默认值、字段名与行为；引用形式如 `ai/types.ts:17`|
|随包发布的文档|`packages/coding-agent/docs/*.md`、README 文件|作者所描述的公开接口；引用形式如 `CA/docs/rpc.md`|
|示例|`packages/coding-agent/examples/**`|可运行的扩展与 SDK 代码|
|测试|`packages/*/test/**`|边界情况中的确切行为|
|采集工具包|`research/capture/`|书中展示的所有事件流、会话行与行数|



代码的优先级高于文档。随包文档与代码不一致时，正文以代码为准，并以“文档 ≠ 代码”提示标明差异；[文档与代码的差异](/pi-104/reference/doc-code)（原书第 213 页）列出了全部此类情况。



采集工具包由两个脚本组成。`one-turn.mjs` 使用 `pi-ai` 中的 `faux` 提供商驱动一个真实的 `AgentSession`，因此无需网络或 API 密钥：一个提示、一次 `read` 工具调用、一个回答。它将事件流与生成的会话文件的每一行写入 `research/out/one-turn.txt`。`stats.py` 则统计固定提交版本中的包、源代码行数、提供商和示例扩展，并写入 `research/out/stats.txt`。每次运行的 ID、时间戳和流式文本增量数量会变化；事件顺序与每种记录的结构不会变化。

### 约定



路径以仓库根目录为基准，并使用四个简写前缀：`ai/` = `packages/ai/src/`，`agent/` = `packages/agent/src/`，`CA/` = `packages/coding-agent/`，`tui/` = `packages/tui/src/`。



行号放在冒号后面，例如 `ai/models.ts:149`，指向提交 `28dcce2` 中的声明。后续提交可能使行号发生变化；其旁边的符号名则不会因此变化。



代码排版：类型、函数、事件、设置键、命令和文件名使用代码字体。像“会话：JSONL 树”（原书第 86 页）这样的交叉引用保留纸质版页码。



记录按 Pi 的实际写入形式展示：每行一个 JSON 对象；本书为便于阅读，以两个空格缩进，并按存储时的键顺序格式化。代码清单若有删节，会用 `…` 标出，并在下方注释中说明省略了什么。

### 插图中的颜色



每幅插图都采用同一套颜色编码，同一种颜色在所有地方都表示同一含义。

|<strong>颜色</strong>|<strong>含义</strong>|<strong>颜色</strong>|<strong>含义</strong>|
|---|---|---|---|
|灰色|用户、宿主，以及 Pi 之外的任何事物|梅紫色|模型、提供商、`pi-ai`、流式传输|
|琥珀色|智能体循环、轮次、队列|蓝色|消息、对话记录、条目|
|水绿色|会话与存储：JSONL、磁盘文件|森林绿|工具、bash、对文件系统的影响|
|紫罗兰色|扩展、钩子、扩展事件|靛蓝色|运行模式与 UI：TUI、RPC、SDK 客户端|
|绿色|配置与资源：设置、技能、提示|玫红色|错误、中止、溢出、文档 ≠ 代码，以及图中特别要你注意的内容|



时序图为每一方设置一条竖直生命线，时间沿页面向下推进。实线箭头表示调用，虚线箭头表示回复或事件，而图中重点讨论的箭头则画得更粗。左侧页边距内的带数字圆圈表示步骤序号。
